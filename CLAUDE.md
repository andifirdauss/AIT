# CLAUDE.md

Panduan untuk Claude Code di repo **ai-thread** (solusi .NET: `AIThread.UI`, `AIThread.API`, `AIThread.Service`, `AIThread.Data`, `AIThread.Common` di `src/`).

## Prioritas MCP

MCP server dikonfigurasi di [.mcp.json](.mcp.json). **Selalu utamakan MCP ini** dibanding tool bawaan atau pengetahuan internal.

### context7 — dokumentasi library
- **Wajib** dipakai sebelum menulis/mengubah kode yang memakai library atau framework (ASP.NET Core, EF Core, Bootstrap, jQuery, NuGet package, dll.).
- Alur: `resolve-library-id` → `get-library-docs` (atau `query-docs`) dengan topik spesifik.
- Jangan mengandalkan ingatan untuk API, signature, atau konfigurasi — verifikasi via context7, terutama untuk versi terbaru.
- Jika context7 tidak menemukan library, baru gunakan WebSearch/WebFetch.

### filesystem — operasi file
- Utamakan tool MCP filesystem (`read_text_file`, `read_multiple_files`, `write_file`, `edit_file`, `list_directory`, `directory_tree`, `search_files`, `get_file_info`) untuk membaca, menulis, dan menjelajah file proyek.
- Gunakan `read_multiple_files` untuk membaca beberapa file sekaligus.
- Akses dibatasi ke `D:/External/Presistence/ai-thread`.
- Fallback ke Read/Edit/Write/Glob/Grep bawaan hanya jika MCP filesystem gagal atau tidak tersedia.

## Konvensi
- Balas dalam Bahasa Indonesia; identifier kode dalam Bahasa Inggris.
- Abaikan folder `bin/`, `obj/`, dan `wwwroot/lib/` (library pihak ketiga) saat menjelajah kode.
- **Service = Interface + Service + partial class per method.** Setiap class yang di-register di DI `AIThread.Service` punya `I<Nama>` di `Interfaces/` berisi semua member publik instance, dengan registrasi `AddSingleton<I<Nama>, <Nama>>()`. Konsumen dan test selalu inject/resolve interface-nya. Class-nya `partial` di folder `<folder asal>/<Nama>/`, namespace tetap folder asal: `<Nama>.cs` berisi primary ctor, base list, field, property, dan nested/type pendukung; `<Nama>.<Method>.cs` satu file per method (public & private, overload satu file, termasuk `[GeneratedRegex]`). Method baru = file baru, member publik baru ikut ke interface. Dikecualikan: static helper, model/record, hosted worker `Background/`. Detail: [docs/10-pengembangan.md](docs/10-pengembangan.md#konvensi-service).
- **Teks untuk user selalu dua bahasa (Indonesia + Inggris)**: UI web, output ke CLI, log aktivitas, pesan validasi/API, menu `AIThread.exe`, Telegram. Tulis berpasangan di tempat pemakaian, jangan satu bahasa saja: C# `Lang.T("Indonesia", "English")` (`AIThread.Common.Localization`), Razor `@Lang.T("…", "…")`, JS `t('…', '…')` dari `window.AIThread` (template berisi ekspresi: `isEn ? \`English ${x}\` : \`Indonesia ${x}\``). `const string` berisi teks user → properti `static string X => Lang.T(…)`. Bahasa aktif = pilihan di sidebar (`SystemSetting.UiLanguage`, `Lang.Set`), kecuali thread dari CLI yang mengikuti bahasa prompt (`TextLanguage.LangOfPrompt` → `Lang.Use` di `ThreadOrchestrator.RunAsync`/`AgentProxyHandler`); menu exe membaca `cli.json`; test memakai `using var _ = Lang.Use("en")`. Perintah chat yang di-parse (`ulangi`/`retry`, `login …`, …) menerima kedua bahasa. Prompt ke model AI, pesan error tool planner, dan log developer (`ILogger`) tetap Bahasa Inggris saja.
- Nama produk di teks yang dibaca user/model adalah **AIT**; identifier & konfigurasi tetap `AIThread`/`aithread` (namespace, `AIThread.exe`, `.aithread/`, provider opencode/Codex, header `X-AIThread-*`, folder `%LOCALAPPDATA%\AIThread`, section `AIThread:` di appsettings).
- **AIT tidak terikat ke satu CLI.** Klien proxy = CLI coding apa pun (Claude Code, Codex CLI, Gemini CLI, opencode, Qwen Code, oh-my-pi, …) lewat format Anthropic/OpenAI/Gemini. Di docs, teks UI, log, komentar, dan jawaban ke user, sebut "CLI" untuk hal yang berlaku umum; sebut nama CLI tertentu hanya untuk yang memang khusus CLI itu (mis. hook `/clear`/`PreToolUse`, `permissions.deny`, `settings.json` = Claude Code; `--profile aithread` = Codex; `.gemini/.env` = Gemini CLI). `ThreadSource.ClaudeCode` = semua thread dari CLI (nama lama, tersimpan di DB; labelnya "CLI"). Panduan per CLI: [docs/03-integrasi-cli.md](docs/03-integrasi-cli.md).
- **Kontrol jendela gaya macOS adalah standar UI** untuk tutup / minimize / maximize; jangan pakai `btn-close` Bootstrap. Merah = tutup, kuning = lipat (modal: dock di bawah layar), hijau = layar penuh (double-click title bar juga; Esc keluar). Razor: `<win-controls for="modal|alert|toast" />` (`TagHelpers/WinControlsTagHelper.cs`), header modal diberi kelas `win-bar` dengan kontrol di kiri judul. Panel/blok kode: `.win` + `.win-bar` (`<win-controls close-label="…" />`), atau dari JS `AIThread.winFrame({ id, title, body, minimized, canClose })` / `AIThread.winControls()`. Merah di `.win` memicu event `win:close` yang ditangani halaman; tanpa itu tombolnya nonaktif (abu-abu). Beri `data-win-id` agar status lipat/layar penuh bertahan saat render ulang; `data-win-persist` menyimpan status lipat antar muat halaman. Perilaku di `site.js` (`initWindows`), gaya di `site.css`.

## Publish npm
- Token npm ada di environment variable user `NPM_TOKEN` (Windows). **Jangan pernah menulis nilainya ke file repo, commit, atau chat.**
- Sebelum `scripts/publish-npm.ps1 -Publish`, naikkan `<Version>` di `src/AIThread.UI/AIThread.UI.csproj` (npm menolak versi yang sudah ada). Skrip menyamakan versi `package.json`.
- Publish memakai `.npmrc` sementara yang dibuat dari `NPM_TOKEN` lalu dihapus; jangan menyimpan `.npmrc` berisi token di folder repo.
- Versi di registry dicek dengan `npm view aithread version`.

  `Hosting/`: entry point `AIThread.exe` (`Cli`: menu interaktif, `tray`, `serve`, `stop`, `setup` export/import profil lewat `SetupCommand`, dll.), ikon tray Win32, autostart. Exe standalone: `scripts/publish-exe.ps1`.
- Test: `tests/AIThread.Tests` (`dotnet test`). Migrasi: `dotnet tool run dotnet-ef migrations add <Nama> --context AIThreadDbContext --project src/AIThread.Data --startup-project src/AIThread.Data`.
